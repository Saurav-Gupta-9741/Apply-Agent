# Chrome Web Store Listing — German (Deutsch)

## Name
ApplyAgent

## Short Description (max 132 chars)
Bewerbungsformulare auf Karriereseiten automatisch ausfüllen. Datenschutzkonform, lokal im Browser. Sie senden ab.

## Detailed Description
Bewerbungs-Autofill für Greenhouse, Ashby, Lever, Breezy, BambooHR, Recruitee, Workable und Unternehmens-Karriereseiten. Workday, iCIMS und Taleo werden noch nicht unterstützt. Ihre Daten bleiben in Ihrem Browser, mit KI-Fragenverständnis auf Ihrem Computer.

WIE ES FUNKTIONIERT:
• Profil, Lebenslauf und Quick Answers einmalig speichern (Kündigungsfrist, Arbeitserlaubnis, Gehaltsvorstellung).
• Formular öffnen und "Ausfüllen" (Alt+Shift+G) drücken. ApplyAgent füllt Felder aus und wählt Optionen passgenau.
• Fragen, die nur Sie beantworten können (Rechtliche Erklärungen, Einwilligungen, Freitexte), werden hervorgehoben.
• Sie prüfen das Formular und klicken selbst auf "Absenden".

WAS ES NIEMALS TUT:
• Funktioniert niemals auf LinkedIn, Indeed, StepStone oder Jobbörsen.
• Behandelt keine Passwörter und löst keine CAPTCHAs.
• Sendet niemals Formulare automatisch ab.
• Sendet keine persönlichen Daten an externe Server: Profil, Lebenslauf und Antworten bleiben in Ihrem Browser. (Discover liest öffentliche Stellenlisten der Unternehmen, ohne Cookies.)

PREISE:
• Free: Unbegrenztes Ausfüllen einzelner Formulare, Antwortspeicher, lokaler Tracker.
• Pro: 9 $ / Monat (ca. 8,50 €). Bulk-Warteschlange, Lebenslauf-Import, KI-Entwürfe, Enterprise-Formulare.
• Founder: 49 $ einmalig (10 Jahre gültig). Keine automatische Verlängerung.
