# Chrome Web Store Listing — Japanese (日本語)

## Name
ApplyAgent

## Short Description (max 132 chars)
プロフィールから採用サイトの応募フォームを自動入力。機密項目は確認、送信は必ずあなたが行います。

## Detailed Description
Greenhouse、Lever、Workday、Ashby、HERP、各社採用ページ対応の応募フォーム自動入力ツール。完全ローカル処理で外部サーバーへの個人情報送信はありません。

使い方:
• プロフィール、履歴書/職務経歴書、基本事項（通知期間、就労ビザ、希望年収）を一度保存。
• 求人応募画面で「入力」（または Alt+Shift+F）をクリック。適切な選択肢を自動選択し項目を入力。
• 同意事項や志望動機など、本人の判断が必要な項目は確認用としてハイライト表示。
• 入力内容を確認し、ご自身で「応募する」をクリック。

安全への配慮:
• LinkedIn、Indeed、転職サイト上での自動化は行いません。
• パスワード管理やCAPTCHA認証の迂回は行いません。
• 勝手に応募送信することはありません。
• データはすべて端末内のブラウザに保存され、外部に送信されません。

料金体系:
• 無料版: 個別応募フォーム入力無制限、回答バンク、応募トラッカー。
• Pro版: 30日間 9ドル（約1,400円）。複数応募キュー、履歴書インポート、ローカルAI下書き。
• ファウンダー版: 49ドル（10年間有効）。自動更新なしの単発決済。
